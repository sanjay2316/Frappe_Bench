# Frappe16

## hooks assissgnment
This repository contains implementations of two Frappe Framework assignments:

- **Basics Python API**
  - Implemented `before_save()` in a custom DocType.
  - Used `doc_events` and Hooks to extend the **User** DocType.

- **Python API Documentation**
  - Created a custom whitelisted API.
  - Demonstrated **Query Builder**, **Document API**, and **Database API**.

- `doctype/test_document/test_document.py` – Controller (`before_save`)
- `hooks.py` – Hook configuration
- `api.py` – Hook function and Whitelisted API# practice_app
